# Storage buckets & policies

Recommended storage buckets to create in Supabase Storage (via the Dashboard or API):

- avatars
- user-files
- audio-files
- subtitle-files
- video-files

Recommendations:
- Use "private" buckets for user files if you plan to serve signed URLs; public buckets are easier but less secure.
- Use storage policies or server-side signed URL generation to avoid exposing raw file paths.

Example policy ideas
- Avatars: public read, authenticated write only to your own path (use RLS on metadata or server-side enforcement)
- user-files: private; use server-side signed URLs for downloads
- audio-files: private; generated by TTS proxy and stored server-side

There is no SQL migration for creating buckets. Use Supabase Dashboard or the Storage API to create the buckets and configure permissions.
